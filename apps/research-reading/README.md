# 智能科研与智能阅读：2026-09-18 公开演示版

本次版本来自本机 5174 原型。门户继续通过 `dist/index.html?view=research` 和 `dist/index.html?view=reading` 打开联合工作台。

## 公开演示资料

首次访问自动加载 `public/demo/manifest.json` 内的演示快照及文件附件。科研区有 11 项有效内容（含 4 张表、28 行数据），阅读区有 5 篇资料与 10 条笔记；回收站中的 1 份资料保留原状态。PDF 原文件、批注和截图保存在访客浏览器的 IndexedDB。

每位访客获得独立的本地副本。修改、上传和评审编辑仅保存在当前浏览器，不会同步给其他访客；刷新不会覆盖已有修改。首次加载发生网络或存储错误时显示重试，不伪装成加载成功。用户明确要求不公开的文档及其原文件、批注、截图均未收入发布快照。

## 开发与发布

使用 Node.js 24 和仓库的 `package-lock.json`：

```sh
npm ci
npm run check
```

`dist/` 是实际发布目录，必须由当前源码重新构建。公共资源路径已适配 GitHub Pages 的 `/gkx-ai-strategy-portal/` 子目录。`src/demoData.ts` 在应用渲染前加载数据，合并访客已有内容时保留原记录并处理编号冲突。

PRD 模式在本地开发时继续使用开发服务；生产静态版读取随站点发布的基线，编辑状态明确标为“本浏览器演示”，不依赖不存在的 Pages 后端。

原型仍不提供真实账号、权限隔离或多人协作后端。历史交付 ZIP 和校验清单仅作为历史归档，不代表本次发布产物。
