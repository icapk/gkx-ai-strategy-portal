# 开发交接说明

## 交付状态

- 技术栈：React 19、TypeScript 5.8、Vite 7、KaTeX。
- 运行方式：纯前端单页应用，本地热更新预览。
- 生产构建：`pnpm build`。
- 当前验证：17 项单元测试、TypeScript 检查和 Vite 生产构建均通过。
- 发布状态：已覆盖发布到既有 GitHub Pages 门户 `https://icapk.github.io/gkx-ai-strategy-portal/`；未创建新站点，`.openai/hosting.json` 不进入开发源码包。

## 已实现范围

### 通用能力

- 文档与笔记统一全文搜索。
- 搜索结果按文档/笔记筛选、分页、打开或定位。
- 个人信息设置与浏览器本地保存。

### 科研文档编辑

- 文本、列表、图片、数学公式、网页书签、分割线六类内容块。
- 插入、排序、删除、撤销、保存失败重试和离开保护。
- KaTeX 公式预览、网页地址校验、图片格式与大小校验。

### 科研数据表格

- 工作台右上角统一入口和全量数据表格管理列表。
- 项目进度与科研数据两类模板。
- 表格视图与表单视图双 Tab；两者共用同一份筛选结果。
- 表格视图支持字段排序、字段管理、单元格编辑、批量选择和删除。
- 表单视图支持记录导航与全部字段只读投影；新增/编辑使用独立弹窗。
- CSV/TSV 多文件本地解析、追加/替换、预览、导出 CSV。
- 文件导入记录、共享权限、搜索、空状态、撤销和本地保存。
- Back/Forward、刷新、失效深链、脏数据确认和跨表状态隔离。

## 数据边界

这是交互原型，不是生产协作后端：

- 文档、数据表格、头像和个人设置保存在当前浏览器 `localStorage`。
- 团队角色、分享通知和协作者权限是本地演示，不会调用真实成员系统。
- 导入 CSV/TSV 时在浏览器本地解析；没有对象存储或服务端病毒扫描。
- “本地预览链接”只在开发服务运行时有效。
- 阅读器和科研内容均使用演示数据。

数据表格当前限制：单文件 2 MiB、一次最多选择 10 个文件、单次/单表最多 500 行、最多 30 个字段、单元格 2,000 字、单表 30 条文件记录、最多 50 位协作者。

当前真正解析的格式只有 CSV 和 TSV。界面中的 XLSX 文件名属于演示附件元数据，不能作为“已支持解析 Excel”的生产能力对外说明。

## 关键稳定性约束

后续修改时不要破坏以下闭环：

1. `表格视图` 与 `表单视图` 必须保留，并共用 `filteredRows`。
2. 表单视图是同一行数据的可视化字段投影，不等同于“新增记录”。
3. 新增/编辑记录必须继续使用独立 Modal，并保留取消确认。
4. `DataTableWorkspace` 必须按文档 ID 设置 React `key`，防止跨表复用旧 state。
5. 浏览器 Back/Forward 必须经过 `onNavigationGuardChange`，同步保存或拦截离开。
6. 表格内容与文档索引的双写失败必须执行补偿回滚并提示回滚结果。
7. 子弹窗出现时，外层页面应 `inert` 或撤销外层 `dialog/aria-modal` 语义。
8. 图标继续使用统一的单色线型体系；新增 IconPark 图标时同步更新 NOTICE。

## 验收命令

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm dev
pnpm preview:check
```

浏览器回归至少覆盖：工作台入口、统领列表、双视图切换、筛选无结果、添加/编辑/取消、立即返回保存、草稿返回确认、Back/Forward、刷新、失效深链和单一模态层。
