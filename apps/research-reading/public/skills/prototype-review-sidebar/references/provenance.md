# 来源与提取边界

基线为门户仓库 `icapk/gkx-ai-strategy-portal` 的提交 `e43daa722f33486641dab6830599522f6d225b4c`（2026-09-20 发布）。模板包含其实际合规、PRD、注释、定位、框选组件及共享样式；不是根据截图重新画一个近似侧栏。

为便于别人直接复制，本版做了这些提取改动：

- 仅保留侧栏导入闭包；不带 App 业务代码、PDF、富文本、表格依赖和 IndexedDB 演示资料。
- 合规、PRD、目标映射集中到 `sidebar.config.ts`，替换为三个通用功能示例；初始注释为空。
- 加入 `ReviewShell` 与宿主准备／恢复契约；最小业务示例只用于验证定位，不能冒充科研或阅读业务功能。
- 所有浏览器保存增加可配置 namespace；默认 browser 模式可同时用于开发和生产构建，避免开发必须有本地API。
- 移除原项目业务资料重置按钮，仅保留当前项目评审示例的备份更新；增加合规保存前的快照冲突检查。
- 去除原项目专用数据迁移链，保留通用 PRD 结构与历史规则；模块内部键仍是 research/reading。
- 相对导入写出扩展名，使随包 Node 原生 TypeScript 测试可独立运行。
- 补齐原应用隐含的基础样式；弹窗样式限定到组件命名空间，关闭图标改为内置字符，移除原应用布局偏移依赖。
- 两个模块的合规详情标题补齐显式“定位”“框选校正”入口，与卡片一致。
- 阅读 PRD 校验改用通用稳定 ID 与宿主选择器，不再要求旧项目 READ-/F 编号或专用 DOM 根；保留结构、唯一性、枚举和区域边界校验。
