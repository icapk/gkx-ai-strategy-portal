# 门户后台管理系统

基于 Figma Make 原型复刻的响应式后台管理前端，包含活动、审批、组织权限、菜单、资源与报告等模块。

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
pnpm preview
```

## 门户集成发布

本项目作为 `gkx-ai-strategy-portal` 的“后台管理一”维护，生产构建输出到 `dist/`，由门户仓库的 GitHub Pages 一并发布：

```bash
pnpm build
```

页面使用相对资源路径，可从门户首页内嵌打开。公告管理与门户首页共用 `gkx-portal-announcements-v1` 本地存储键；当前静态原型的数据仅在同一浏览器内共享。

## 主要交互

- 左侧导航展开、收起与多模块切换
- 顶部全局搜索、消息通知与用户菜单
- 活动新增/编辑/查看/删除弹窗
- 首页公告新建、预览、草稿、立即/定时发布与下线
- 内容与表单审批详情、通过与驳回
- 用户、角色、权限配置弹窗
- 资源上传弹窗与网格视图
- 响应式移动端侧栏
