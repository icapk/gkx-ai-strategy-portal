# Education illustration set

Generated with the built-in image_gen tool for the four homepage education cards. PNG alpha is preserved; all artwork is local and rendered with object-fit:contain.

Shared direction: milky translucent ice-blue and white frosted glass, restrained cobalt/cyan accents, rounded forms, soft upper-left studio light, three-quarter view, transparent backgrounds, no text or logos.

## Runtime assets and final prompts

- Play: `play-v2.png` — virtual laboratory with recognizable experimental apparatus and a small abstract digital control panel. Final prompt: [play-v2-prompt.txt](play-v2-prompt.txt).
- Learn: `learn.png` — open frosted-glass book and play tile. Final prompt: [learn-prompt.txt](learn-prompt.txt).
- Build: `build.png` — glass assistant robot and interlocking blocks. Final prompt: [build-prompt.txt](build-prompt.txt).
- Compete: `compete.png` — glass trophy. Final prompt: [compete-prompt.txt](compete-prompt.txt).

The first play draft (`play.png`/`play-prompt.txt`) is retained as an unused generation source. The user requested a clearer virtual-experiment composition while keeping its material style. Illustration backplates, borders and clipping were removed from the webpage at the user's request.
