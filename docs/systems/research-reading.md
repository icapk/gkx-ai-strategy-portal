# 智能科研与智能阅读

智能科研与智能阅读属于同一工作台应用，可从门户「工作台」菜单分别进入，并通过页面中的「智能科研」「智能阅读」页签切换。

## 进入工作台

展开门户顶部「工作台」，根据当前任务选择「智能科研」或「智能阅读」。页面在门户工作区加载。

[返回门户](index.html)

## 智能科研

智能科研提供工作台、个人空间、团队空间和存档管理等页面。

| 位置 | 当前页面内容 |
| --- | --- |
| 工作台 | 按最近浏览、我的收藏、归我所有、与我共享查看记录 |
| 个人空间 | 查看个人内容，使用新建内容或新建文件夹入口组织资料 |
| 团队空间 | 查看团队空间中的内容与团队相关入口 |
| 存档管理 | 查看存档内容 |

先选择内容所在的空间，再从列表中打开目标文档或表格。需要整理资料时，使用页面提供的新建内容和新建文件夹入口。

## 智能阅读

智能阅读页面提供「PDF 增强阅读」入口，可查看文献列表、选择文件并进入阅读页面。

1. 选择「智能阅读」页签，进入 PDF 增强阅读页面。
2. 使用文件选择区选择页面支持的 Word 或 PDF 文件。
3. 选择目标笔记库，点击「上传文件」，查看页面反馈。
4. 在阅读页面查看文献内容，并使用页面提供的笔记与阅读入口。

上传或解析失败时，根据当前错误提示重试或重新选择文件。离开仍有未保存内容的阅读页面时，按提示选择保存、继续编辑或放弃修改。
