# 语音增强与适配工作台

门户「应用管理」中的「语音增强与适配工作台」入口连接语音工作台，当前入口页面标题为「智能语音输入交互模块」。

> 以下说明对应当前原型中可见的菜单与操作入口。

## 进入工作台

展开门户顶部「应用管理」，点击「语音增强与适配工作台」。在门户工作区加载页面后，可通过左侧菜单切换功能。

## 语音识别核心功能

| 菜单 | 阅读与操作入口 |
| --- | --- |
| 自定义语义库管理 | 查看语义库及专属词汇，页面提供新建语义库、添加词汇与批量导入入口 |
| 实时语音转写 | 查看录入与转写区域，页面提供暂停、继续、结束录入等控制 |
| 离线转写模型下载 | 查看离线模型、版本信息及待同步文档 |

## 编辑与输出

左侧「编辑与输出功能」提供「实时混合编辑」和「历史版本回溯」入口。选择相应入口后，查看转写文本编辑与版本相关页面。

## 阅读转写内容

进入转写页面后，先核对文档名称和当前状态，再查看文本内容及页面提供的编辑操作。录入、模型下载和同步等结果应以实际接入环境返回的信息为准。
