# 集群服务

集群服务在门户顶部集中提供科技交流、资源服务、决策支持与科学数据等页面入口。各服务共用集群服务应用，通过不同页面展示相应内容。

## 选择服务页面

在门户顶部展开「集群服务」，按当前任务选择对应服务。所选页面在门户工作区加载，门户导航继续可用。

[返回门户](index.html)

## 服务目录

| 服务入口 | 使用方向 |
| --- | --- |
| 科技信息交流 | 浏览科技交流内容与话题 |
| 科技资源服务 | 查找相关科技资源与服务信息 |
| 科技决策支持 | 浏览决策支持相关信息 |
| 科学数据中心 | 查看科学数据资源 |
| 新型高端智库 | 查看智库相关内容 |
| 科技专题服务 | 围绕特定主题查看研究资料 |

## 浏览与切换

进入页面后，按页面提供的栏目、内容卡片或服务入口继续查看信息。需要切换集群服务时，重新展开门户「集群服务」菜单选择目标页面；也可以通过顶部其他业务导航进入相应系统。
