# AI 分析与智能分发工作台

从门户「应用管理」进入 AI 分析与智能分发工作台，在门户工作区查看订阅规则、情报需求、流转与分发相关页面。

> 以下说明对应当前原型中可见的菜单与操作入口。

## 进入工作台

展开门户顶部「应用管理」，点击「AI 分析与智能分发工作台」。进入后，通过工作台左侧菜单切换功能页面。

[返回门户](index.html)

## 功能导航

| 菜单 | 页面中可查看的内容 |
| --- | --- |
| 复合订阅规则引擎搭建 | 规则条件、冲突校验、规则清理建议与订阅推荐 |
| 创新需求与情报主动征集窗口 | 需求主题、提报人、分派对象与当前状态 |
| 创新情报内部定向批示流转 | 情报流转与批示相关信息 |
| AI 分发置信度动态阈值管控 | 置信度阈值、分发与审核区间 |
| 创新主体跨域偏好关联挖掘 | 创新主体偏好与关联内容 |
| 模型分发路径可视化追踪地图 | 分发路径、规则命中与接收环节 |
| 专家人工干预与离线标注重镇 | 专家干预、标签修正与标注相关入口 |

## 查看与配置订阅规则

1. 选择「复合订阅规则引擎搭建」。
2. 查看规则构建器中的行业、事件、风险、时间等条件组件及当前规则条件。
3. 通过页面提供的「新建订阅规则」「冲突校验」「保存规则」等入口了解对应配置流程。

## 查看分发路径

选择「模型分发路径可视化追踪地图」，按页面提示查看情报、模型标签、规则命中、频控及接收人的路径信息。需要切换业务系统时，使用门户顶部导航。
