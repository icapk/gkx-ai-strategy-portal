# 管理后台

管理后台从门户「应用管理」进入，按「系统管理」和「权限管理」组织管理页面。

> 以下说明对应当前原型中可见的管理菜单与表单入口。

## 进入管理后台

1. 展开门户顶部的「应用管理」。
2. 点击「管理后台」。
3. 通过后台左侧菜单选择管理对象，在右侧查看对应列表和表单。

## 系统管理

| 菜单 | 对应内容 |
| --- | --- |
| 报告管理 | 报告列表与报告相关操作 |
| 公告管理 | 公告内容与管理操作 |
| 审核管理 | 流程中心、表单中心与评论审核 |
| 埋点管理 | 埋点信息管理与埋点数据统计 |

## 权限管理

| 菜单 | 对应内容 |
| --- | --- |
| 用户管理 | 用户列表与用户信息 |
| 角色管理 | 角色列表与角色配置 |
| 页面管理 | 页面条目与页面信息 |
| 资源管理 | 资源条目与资源信息 |
| 权限配置 | 页面中提供的权限配置项 |

## 查看和维护记录

选择具体菜单后，先使用该页面提供的条件定位记录，再点击记录对应的查看或编辑操作。填写表单时以当前页面中的字段、必填标记和提示为准，保存后查看页面返回的反馈。
