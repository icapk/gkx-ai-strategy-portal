# 关注期刊目录接入

期刊目录默认每页 10 条，搜索后回到第一页。勾选以稳定期刊 ID 保存，翻页和搜索不应清除其他页的选择。

## 当前交付边界

深势期刊接口由深势后补。目前没有供应方可调用地址、鉴权及字段映射，真实接口尚未接通。现有《智能推荐_深势接口修改与确认清单.xlsx》`sheet1` 第 6 行 R-05 也将期刊目录搜索、分页列为待补接口。

未配置服务时，`journal-catalog.js` 提供 24 条明确带“原型”的虚构目录，供验证 10 / 10 / 4 条分页及搜索。前 8 条沿用既有关注对象。示例数据不代表深势接口返回结果。

## 门户后端适配约定（待接入）

以下结构是前端预留的**门户同源网关约定**，不是已确认的深势原始接口契约。供应方交付后，由门户后端完成鉴权、字段映射和必要的分页转换；浏览器中不放供应方密钥。

在加载目录脚本前配置门户同源地址：

```js
window.PORTAL_JOURNAL_CATALOG_CONFIG = {
  endpoint: '/api/journal-catalog'
};
```

前端发送 `GET ?q=关键词&page=1&pageSize=10`，使用同源凭据。响应约定如下：

```json
{
  "items": [
    { "id": "稳定的期刊ID", "name": "期刊名称", "issn": "可选ISSN", "domains": ["可选领域"] }
  ],
  "total": 1,
  "page": 1,
  "pageSize": 10
}
```

`id` 为非空字符串；`total` 为非负整数；`page`、`pageSize` 与请求一致；每页条目数量须与总数相符。目录返回条目按 ID 缓存供关注校验。配置远程服务后，错误、超时或格式异常会明确报错，不回退为示例数据。请求支持取消，超时为 12 秒。

真实接入还需确认：供应方地址与鉴权、期刊 ID / 名称 / ISSN / 领域映射、关键词与分页语义，以及论文 `journalId` 和筛选 `journalIds`。实际期刊关联使用 ID，不用文献 `source` 名称代替 ID。真实关注状态服务与联调验收仍需后续完成。
